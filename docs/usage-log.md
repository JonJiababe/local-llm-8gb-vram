# 使用记录

真实使用中观察到的东西。时间倒序，一条一次会话或一件事。

写这条记录的目的：**回答"跑起来之后到底怎么样"**。跑分和压测在别处，这里只记实际用下来的结果，包括判断被推翻的部分。

格式固定，方便回溯：

```

- 配置：模型 / 上下文 / 思考开关
- 任务：
- 结果：
- 问题：
- 是否推翻了之前的判断：
```

出现问题如果有普适价值，同时更新到 `README.md` 的坑列表或 `docs/deployment-story.md`。

## 2026-10-25 · 在长会话里切成 9B，撞了 25 万 token

- 配置：Qwen3.5-9B-Q4_K_M / ctx 65536 / 思考关闭
- 任务：在一个已经聊了很久的会话里继续干活
- 结果：直接 400。服务端日志连续四次 `283646 / 255133 / 254777 / 238592` tokens，全部超过 65536。切模型前最后一次正常请求只有 `18920` tokens
- 问题：agent 框架默认关闭全部上下文压缩插件（`compaction-basic` / `command-compact` / `tool-result-pruner` 都是 `disabled: true`），历史无界累积
- 是否推翻之前的判断：**是**。此前认为"64K 上下文足够应付 agent 场景"，实际情况是框架会把整段历史反复重发，64K 在长会话里很快见底

## 2026-10-25 · 首次接入 DSH，路由静默失效

- 配置：同上，尚未调过任何参数
- 任务：把本地模型配成 DSH 的一条 pi-ai 路由
- 结果：调用返回 `null`，没有任何报错
- 问题：省略了 `apiKeyEnv`。文档写的是"省略则不认证"，但对自行声明的路由来说，缺这一项会导致整条路由不注册
- 是否推翻之前的判断：**是**。此前以为配置写错会有报错，实际上这类错误是完全静默的。定位靠的是看对端日志有没有收到请求

## 2026-10-25 · 首次启动，显卡没被用上

- 配置：Qwen3.5-9B-Q4_K_M / 默认参数
- 任务：跑第一次推理
- 结果：能跑、答案正确，速度只有 9 tok/s 左右
- 问题：缺 `cudart64_12.dll` 等 CUDA runtime，`--list-devices` 返回 `(none)`，全部推理落在 CPU 上。全程没有任何报错
- 是否推翻之前的判断：**是**。此前以为"慢"是 55W 笔记本 GPU 的正常水平，还去调了半小时量化参数。补上 runtime 后 9 tok/s → 48 tok/s
